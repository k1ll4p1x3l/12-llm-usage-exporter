# Writing project

## Trigger

- Use for chapters, essays, long docs, reports, knowledge-base content, or substantial editing.
- Use when the output should be coherent across multiple sections or sessions.

## Inputs

- Audience, purpose, tone, length, and target format.
- Existing outline, glossary, style notes, or source material.
- Facts that need verification versus original prose that can be drafted directly.

## Workflow

1. Define audience and purpose before drafting.
2. Outline long pieces before writing full prose.
3. Draft or edit in sections that can be reviewed independently.
4. Track terms, claims, and tone consistency across sections.
5. Mark factual claims that need sourcing.
6. End with change notes and the next recommended section.

## Stop / Approval Rules

- Stop before copying protected text verbatim beyond fair use.
- Stop if the requested tone or claim set conflicts with evidence or policy.
- Do not bury unresolved factual gaps inside polished prose.

## Checks

- Audience and tone are explicit.
- Structure exists before long drafting.
- Claims needing research are marked.
- The next writing step is clear.

## Output

```text
## Audience / purpose
...

## Outline or section
...

## Change notes
- ...

## Consistency / fact gaps
- ...

## Next section
- ...
```
